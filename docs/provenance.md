# 来源与版本差异

本项目根据用户提供的《PDF、Word、Excel 文档工作流与 Skill 搭建记录》（2026-10-27）重建。记录描述了旧版 1.0.3，但本次未取得旧版脚本及原始测试报告，所以本仓库从独立版本 0.1.0 开始。

保留原意：本地指定目录、原件不动、带出处检索、查重、增量快照、归档副本和异常清单。

新增：跨 AI 的 TXT/Markdown/JSON 证据包、复制提示词、逐平台兼容性证据、标准/WorkBuddy 双构建包、可重复运行的测试及 CI 配置。

不同点：sync 有逐文件异常时退出码为 2；不沿用旧记录中“异常批次也返回 0”的约定。超出字符或解析资源限制的文件整份报错，不返回可能被误认为完整的截断片段。OCR 有调用入口，但本次没有成功识别验收。

历史“28 项通过”不是本版本证据。原始聊天、截图、私人路径及未附带的历史报告不放入公开仓库。项目不是任何 AI 厂商的官方产品，也没有市场认证或客户实际使用结论。
